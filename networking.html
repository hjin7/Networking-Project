Networking Concepts

Thank you for checking out the Network concepts page!

Here are some basic networking terms:

What is DNS?

It's stands for Domain Name System. It translate domain names into IP address.

What is an IP Address?

It's a numerical address assigned to a device on a network.

What is DHCP?

It's a protocol that automatically assigns IP addresses and other network settings to devices.

What is a Router?

It connects different networks and sends data between them.

What is a Switch?

It connects multiple devices within the same local network and sends data to the correct device
